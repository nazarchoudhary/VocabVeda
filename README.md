# VocabVeda | The Art of Words

## Description
VocabVeda is a vocabulary-building website designed to help users improve their English vocabulary. Users can search word meanings, save favourite words, practise through quizzes, and track their learning progress. The website is built using HTML, Tailwind CSS, and Vanilla JavaScript.

## Features
- Search English words and view their definitions.
- Explore vocabulary and learn new words.
- Save favourite words for future revision.
- Practise vocabulary through interactive quizzes.
- Track learning progress and quiz accuracy.
- Switch between light and dark themes.
- Responsive design for desktop and mobile devices.
- View pronunciation information where available.

## API Used
**English Wiktionary REST API**

- **API Endpoint:** https://en.wiktionary.org/api/rest_v1/page/definition/

The website uses the API endpoint in `script.js` to retrieve definitions for searched words. The word is appended to the endpoint dynamically. No API key is configured in the project.
